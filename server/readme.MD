# VisionGuard server

Node.js 22 server and web dashboard. Run it locally:

```bash
npm ci
cp ../.env.example .env      # then edit
BWC_TOKEN=change-me node server.js     # http://localhost:3000
npm test
```

Documentation: [`docs/GUIDE.md`](../docs/GUIDE.md) (operations) and [`docs/DEPLOYMENT.md`](../docs/DEPLOYMENT.md) (production).
