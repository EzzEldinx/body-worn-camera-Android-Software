Automatic updates over the network

Upload a build first.
For cameras that are not near a docking station: set them to Over Wi-Fi or Over Wi-Fi and SIM below, or on the Docking page (Registered). The server sends the update to one camera first and only continues when that camera has run the new build for a few minutes (a camera updated on a docking station counts too). A camera that is recording waits; a camera on a dock is left to the dock. If the first cameras refuse the build, everything stops until you press Resume.

"Update selected" sends the update now, over whatever network the camera has. A camera that is recording waits until it stops (unless you tick "even while recording"), downloads the APK from this server, checks it, installs it and restarts. Offline cameras are skipped. "Network updates" decides whether the server does this by itself for a camera: Over Wi-Fi only works once the camera runs the newest app (put it on a docking station once); over the SIM uses mobile data, about 55 MB each time.
